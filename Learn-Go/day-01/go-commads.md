# 'Go' Commands

 - go run: Compiles and runs a Go program immediately without saving an executable file.
 - go build: Compiles your Go package and saves a reusable binary file in your current directory.
 - go mod init: Creates a new Go module by initializing a go.mod file to manage dependencies.
 - go get: Downloads, installs, and updates external packages and their dependencies.
 - go fmt: Automatically formats all Go source files in the directory to match language standards.
 - go test: Runs automated test files ending in _test.go within your project.
 - go version: Displays the currently installed version of Go on your system.
 - go help: Lists all available commands and provides documentation for specific tools.

```bash
# 1. Initialize a new project module
go mod init myproject

# 2. Run your code file (e.g., main.go)
go run main.go

# 3. Build a standalone executable binary
go build main.go
```
